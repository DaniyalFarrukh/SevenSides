# Admin Page Override
- **Layout**: Sidebar navigation (collapsible). Dense dashboard layout.
- **Typography**: Reduce base font size slightly for data tables. 
- **Spacing**: Use `--space-sm` and `--space-xs` more liberally to fit more data. `--density 8` equivalent.
- **Components**: Kanban board for live orders, data tables with pagination/filters, charts.
- **Colors**: Keep it clean; less block-based and playful, more professional and utilitarian. Use semantic colors (Green for delivered, Red for rejected).
